«class»Limite

Attributs

definition
\(\lim_{X\to a}f(X)=\ell\) si \(\forall\epsilon>0\ \exists\delta>0,\ 0\lt\|X-a\|\lt\delta\Rightarrow|f(X)-\ell|\lt\epsilon\).
unicite
La limite doit être la même quel que soit le chemin suivi pour approcher \(a\). Deux chemins, deux valeurs : pas de limite.

Méthodes

boolean existe(f, (0,0))
  1. Tester les trois directions usuelles : \(f(0,y)\), \(f(x,0)\), \(f(x,x)\).
  2. Si deux résultats diffèrent : la limite n'existe pas, c'est terminé.
  3. S'ils sont égaux à \(\ell\) : on ne peut rien conclure. Il faut prouver, avec l'une des trois méthodes ci-dessous.
Exemple. \(f=\dfrac{x^2-y^2}{x^2+y^2}\) : \(f(x,0)=1\) et \(f(x,x)=0\), pas de limite en \((0,0)\).
double parPolaires(f)
  1. Poser \(x=r\cos\theta,\ y=r\sin\theta\), puis simplifier avec \(x^2+y^2=r^2\).
  2. Faire tendre \(r\to0\). Le résultat ne doit pas dépendre de \(\theta\).
Exemple. \(\dfrac{x^2y}{x^2+y^2}=r\cos^2\theta\sin\theta\to0\).
double parMajoration(f) // gendarmes
  1. Majorer \(|f(x,y)-\ell|\) par une quantité qui tend vers 0.
  2. Inégalité utile : \(x^2+y^2\ge2|x||y|\), donc \(\dfrac1{x^2+y^2}\le\dfrac1{2|x||y|}\).
Exemple. \(\left|\dfrac{xy^3}{x^2+y^2}\right|\le\dfrac{|xy^3|}{2|x||y|}=\dfrac{y^2}2\to0\).
double parDL(f)

Remplacer \(\sin,\cos,\exp,\ln\) par leur développement limité en 0 le long de chaque direction : \(\sin u=u-\frac{u^3}{6}+o(u^3)\), \(\cos u=1-\frac{u^2}2+\frac{u^4}{24}+o(u^4)\).

Exemple. \(f=\dfrac{\cos x-1+x^2/2}{x^4+y^4}\) : \(f(0,y)=0\), \(f(x,0)\to\frac1{24}\), \(f(x,x)\to\frac1{48}\). Pas de limite.

Attributs

ChampScalaire
\(f:D\to\R\). À chaque point \(M(x,y,z)\) un nombre \(f(M)\). Exemple : \(f=x+y^2\).
ChampVecteurs
\(\v F:D\to\R^3,\ \v F=(f_x,f_y,f_z)\). À chaque point un vecteur. Exemple : \(\v F=(x+y^2,\ yz+2,\ 1)\).
«operator»Nabla

Attributs

nabla
\(\v\nabla=\Big(\pd{}x,\pd{}y,\pd{}z\Big)\). Ce n'est pas un vecteur, c'est un opérateur : il sert à retenir les formules.

Méthodes

ChampVecteurs grad(ChampScalaire f) // f de classe C1
\[\grad f=\v\nabla f=\Big(\pd fx,\pd fy,\pd fz\Big)\]
Exemple. \(f=xz+y^2\) : \(\v\nabla f=(z,2y,x)\).
ChampScalaire div(ChampVecteurs F) // F de classe C1
\[\Div\v F=\v\nabla\cdot\v F=\pd{f_x}x+\pd{f_y}y+\pd{f_z}z\]

Mesure la tendance du champ à se disperser.

Exemple. \(\v F=(x+y^2,\ yz+2,\ ze^x)\) : \(\Div\v F=1+z+e^x\).
ChampVecteurs rot(ChampVecteurs F) // F de classe C1
\[\rot\v F=\v\nabla\wedge\v F=\begin{pmatrix}\pd{f_z}y-\pd{f_y}z\\[4pt] \pd{f_x}z-\pd{f_z}x\\[4pt] \pd{f_y}x-\pd{f_x}y\end{pmatrix}\]

Mesure la façon dont le champ tourne autour d'un point. Se calcule comme un produit vectoriel avec \(\v\nabla\).

Exemples. Même \(\v F\) : \(\rot\v F=(-y,\ -ze^x,\ -2y)\).   \((x,y,z)\) : rot nul.   \((z,x,y)\) : rot \(=(1,1,1)\).
ChampScalaire laplacien(ChampScalaire f) // f de classe C2
\[\Delta f=\pd{^2f}{x^2}+\pd{^2f}{y^2}+\pd{^2f}{z^2}\]
Exemple. \(f=xz+y^2\) : \(\Delta f=2\).
ChampVecteurs laplacien(ChampVecteurs F) // surcharge
\[\v\Delta\v F=(\Delta f_x,\ \Delta f_y,\ \Delta f_z)\]
Exemple. \(\v F=(x+y^2,\ yz+2,\ ze^x)\) : \(\v\Delta\v F=(2,0,ze^x)\).

Attributs

definition

boolean estConservatif(F, D)
  1. Vérifier que \(D\) est un ouvert étoilé et \(\v F\) de classe \(C^1\).

  3. \(\rot\v F=\v0\) : conservatif. Sinon non, car \(\rot(\grad f)=\v0\) toujours.

Attributs

sens
Pour \(f\ge0\) continue sur \(D\) borné, \(\iint_Df(x,y)\,\dd x\,\dd y\) est le volume entre la surface \(z=f(x,y)\) et le plan \(xOy\), au-dessus de \(D\).
proprietes
Linéaire. Positive si \(f\ge0\). Croissante, d'où \(\big|\iint_Df\big|\le\iint_D|f|\). Additive : \(\iint_{D_1\cup D_2}=\iint_{D_1}+\iint_{D_2}\) si \(D_1,D_2\) disjoints.
aire
\(\text{Aire}(D)=\iint_D\dd x\,\dd y\).

Méthodes

double surRectangle(f, [a,b]×[c,d])
\[\iint_Df=\int_c^d\Big(\int_a^bf(x,y)\,\dd x\Big)\dd y=\int_a^b\Big(\int_c^df(x,y)\,\dd y\Big)\dd x\]

L'ordre est libre. Si \(f(x,y)=g(x)\,h(y)\) (séparable) : \(\iint_Df=\int_a^bg(x)\,\dd x\times\int_c^dh(y)\,\dd y\).

Exemples. \(\iint e^{x+y}\) sur \([0,1]\times[1,2]\) \(=(e-1)(e^2-e)\).   \(\iint(x^2y+2y^3)\) sur \([-1,1]\times[0,1]\) \(=\frac13+1=\frac43\).
double surDomaineQuelconque(f, D)
  1. Dessiner \(D\).
  2. L'écrire en tranches : \(a\le x\le b,\ y_1(x)\le y\le y_2(x)\).
  3. Intégrer d'abord en \(y\) entre les bornes variables : le résultat dépend de \(x\).
  4. Intégrer ce résultat en \(x\) sur \([a,b]\).
\[\iint_{D}f=\int_a^b\Big(\int_{y_1(x)}^{y_2(x)}f(x,y)\,\dd y\Big)\dd x\]

piègeLes bornes qui dépendent d'une variable vont toujours à l'intérieur. Les bornes extérieures sont des constantes.

Exemple. \(\iint xy\) sur le triangle \(0\le y\le x\le1\) : \(\int_0^1x\cdot\frac{x^2}2\,\dd x=\frac18\). Sur le disque unité : 0 par symétrie.

Calculer \(\iint_De^{-(x^2+y^2)}\,\dd x\,\dd y\) sur le disque de centre \(O\) et de rayon \(R\).

voir la solution

Méthode : ChangementDeVariables.appliquer()

  1. Polaires : \(\int_0^{2\pi}\dd\theta\int_0^Re^{-r^2}\,r\,\dd r\).
  2. \(\int_0^Rre^{-r^2}\,\dd r=\Big[-\dfrac12e^{-r^2}\Big]_0^R=\dfrac{1-e^{-R^2}}2\).

return \(\pi\big(1-e^{-R^2}\big)\).

void volumeDuCone()

Calculer le volume du cône \(x^2+y^2\le z^2,\ 0\le z\le a\).

voir la solution

Méthode : IntegraleTriple.parChangementDeVariables()

  1. Cylindriques : \(0\le r\le z\), \(\theta\in[0,2\pi]\), \(z\in[0,a]\). La borne de \(r\) dépend de \(z\) : on intègre en \(r\) d\'abord.
  2. \(\int_0^{2\pi}\dd\theta\int_0^a\Big(\int_0^zr\,\dd r\Big)\dd z=2\pi\int_0^a\dfrac{z^2}2\,\dd z\).

return \(\dfrac{\pi a^3}3\).

ch5.curvilignes

void calculDirect()

Calculer \(\oint_Cx\,\dd y-y\,\dd x\) sur le cercle de centre \(O\) et de rayon \(R\), sens trigonométrique.

voir la solution

Méthode : IntegraleCurviligne.calculDirect()

  1. \(\gamma(t)=(R\cos t,R\sin t)\), \(\dd x=-R\sin t\,\dd t\), \(\dd y=R\cos t\,\dd t\).
  2. \(x\,\dd y-y\,\dd x=R^2(\cos^2t+\sin^2t)\,\dd t=R^2\,\dd t\).
  3. Contrôle par Green-Riemann : \(\pd Qx-\pd Py=2\), donc \(2\times\pi R^2\).

return \(2\pi R^2\).

void formeExacte()

Calculer \(\int_{AB}(2xy+1)\,\dd x+(x^2+2y)\,\dd y\) de \(A(0,0)\) à \(B(1,2)\).

voir la solution

Méthode : FormeDifferentielle.integrer()

  1. \(\pd Qx=2x=\pd Py\) : fermée sur \(\R^2\) étoilé, donc exacte.
  2. \(\pd fx=2xy+1\Rightarrow f=x^2y+x+g(y)\), puis \(\pd fy=x^2+g\'(y)=x^2+2y\Rightarrow g=y^2\).
  3. \(f=x^2y+x+y^2\), \(f(B)=2+1+4=7\), \(f(A)=0\).

return \(7\), quel que soit le chemin de \(A\) à \(B\).

void greenRiemann()

Calculer \(\oint_Cy^2\,\dd x+3xy\,\dd y\), où \(C\) est le bord du demi-disque \(x^2+y^2\le1,\ y\ge0\), sens trigonométrique.

voir la solution

Méthode : GreenRiemann.appliquer()

  1. \(C\) est fermée et bien orientée.
  2. \(\pd Qx-\pd Py=3y-2y=y\).
  3. \(\iint_\Delta y\,\dd x\,\dd y=\int_0^\pi\sin\theta\,\dd\theta\int_0^1r^2\,\dd r=2\times\dfrac13\).

return \(\dfrac23\).

ch6.surfaces

void fluxDirect()

Calculer le flux sortant de \(\v F=(x,y,0)\) à travers la surface latérale du cylindre \(x^2+y^2=1,\ 0\le z\le2\).

voir la solution

Méthode : Flux.calculDirect()

  1. \(\Psi(\theta,z)=(\cos\theta,\sin\theta,z)\), \(\v T_\theta\wedge\v T_z=(\cos\theta,\sin\theta,0)\), sortant.
  2. \(\v F(\Psi)\cdot(\v T_\theta\wedge\v T_z)=\cos^2\theta+\sin^2\theta=1\).
  3. \(\int_0^2\dd z\int_0^{2\pi}\dd\theta\).

return \(4\pi\).

void ostrogradsky()

Calculer le flux sortant de \(\v F=(x,y,z)\) à travers la sphère de centre \(O\) et de rayon \(R\).

voir la solution

Méthode : GreenOstrogradsky.appliquer()

  1. La sphère est fermée, elle entoure la boule \(\Omega\).
  2. \(\Div\v F=3\).
  3. \(\iiint_\Omega3=3\times\dfrac43\pi R^3\).

return \(4\pi R^3\).

void stokes()

Calculer le flux de \(\rot\v F\) à travers la demi-sphère \(x^2+y^2+z^2=1,\ z\ge0\), orientée vers le haut, pour \(\v F=(-y,x,0)\).

voir la solution

Méthode : Stokes.appliquer()

  1. Bord : le cercle \(\gamma(t)=(\cos t,\sin t,0)\), sens trigonométrique vu d\'en haut.
  2. \(\oint\v F\cdot\dd\v l=\int_0^{2\pi}\big(\sin^2t+\cos^2t\big)\dd t\).
  3. Contrôle : \(\rot\v F=(0,0,2)\), flux à travers le disque \(z=0\) : \(2\times\pi\).

return \(2\pi\).
