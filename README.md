# Analyse 3 en Java

Fiche méthode du cours d'Analyse 3 (ECE Lyon, ING2), chapitres 1 à 6, organisée comme un projet Java :
un chapitre est un package, une notion est une classe, et les liens entre chapitres sont des imports.

## Contenu

- `index.html` : la fiche interactive. Ouvre-la dans un navigateur (connexion nécessaire pour l'affichage des formules).
  - diagramme des liens entre chapitres
  - 26 classes : attributs (formules à connaître) et méthodes (techniques étape par étape)
  - formulaire (trigonométrie, intégrales usuelles, primitives, DL)
  - exceptions : les erreurs classiques par chapitre
  - quiz : 56 questions à choix multiples
  - 18 exercices d'entraînement corrigés
- `analyse3-fiche-a-imprimer.pdf` : la version papier, 7 pages A4.

## Page d'entrée

La fiche demande un prénom et un nom avant de s'afficher. Ils sont envoyés, avec la date de la visite, à l'auteur de la fiche.

## Avertissement

Fiche de révision personnelle rédigée à partir du poly du cours. Le formulaire, les exceptions, le quiz et les
exercices ne viennent pas du poly et n'ont pas été relus par un enseignant : à recouper avec le cours.
